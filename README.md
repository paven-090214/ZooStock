# ZooStock

야생동물을 가상의 코인으로 만들어 매수·매도할 수 있는 모의 투자 웹사이트입니다.

## 조원
- 마성혁
- 안수환

## 기술 스택

| 구분 | 기술 |
|---|---|
| Backend | Java 17, Spring Boot |
| Frontend | React, Vite, JavaScript |
| Database | PostgreSQL |
| ORM | Spring Data JPA |
| Build | Gradle |
| Deployment | Docker, 개인 홈서버 |

## Spring Boot Dependencies

- Spring Web
- Spring Data JPA
- PostgreSQL Driver
- SpringBootDevTools
- Flyway Migration
- Spring Security
- JJWT library
- Swagger UI
- lombok

## 사용 API
- iNaturalist API
